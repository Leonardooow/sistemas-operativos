 # Portafolio de Sistemas Operativos
## Comandos básicos de Git

| Linux 🐧 | ¿Qué hace? | Acción | Windows 🪟 | ¿Qué hace? | Acción |
|---|---|---|---|---|---|
| `echo "# portafolio-so-rumipamba" >> README.md` | Crea el archivo README y agrega el título | Crear/editar archivo | `echo "# portafolio-so-rumipamba" >> README.md` | Crea el archivo README y agrega el título | Crear/editar archivo |
| `git init` | Inicializa un repositorio Git | Crear repositorio | `git init` | Inicializa un repositorio Git | Crear repositorio |
| `git add README.md` | Prepara el README para guardarlo | Agregar archivo | `git add README.md` | Prepara el README para guardarlo | Agregar archivo |
| `git commit -m "first commit"` | Guarda los cambios en el historial de Git | Crear commit | `git commit -m "first commit"` | Guarda los cambios en el historial de Git | Crear commit |
| `git branch -M main` | Cambia el nombre de la rama actual a `main` | Configurar rama | `git branch -M main` | Cambia el nombre de la rama actual a `main` | Configurar rama |
| `git remote add origin https://github.com/rudaruza20/portafolio-so-rumipamba.git` | Conecta el repositorio local con GitHub | Conectar repositorio | `git remote add origin https://github.com/rudaruza20/portafolio-so-rumipamba.git` | Conecta el repositorio local con GitHub | Conectar repositorio |
| `git push -u origin main` | Sube los commits de la rama `main` a GitHub | Subir proyecto | `git push -u origin main` | Sube los commits de la rama `main` a GitHub | Subir proyecto |
