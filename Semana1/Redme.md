# Guía de administración de S.O. Linux y Windows - Semana 1

# Listado de comandos básicos

### Linux
- `ls` - Muestra el contenido del directorio actual.
- `pwd` - Muestra la ruta del directorio actual.
- `cd` - Cambia de directorio.
- `mkdir nombre` - Crea una carpeta nueva.
- `rm archivo` - Elimina un archivo.
- `rm -r carpeta` - Elimina una carpeta y su contenido.
- `cp origen destino` - Copia archivos o carpetas.
- `mv origen destino` - Mueve o renombra archivos.
- `cat archivo` - Muestra el contenido de un archivo.
- `chmod permisos archivo` - Cambia los permisos de un archivo.
- `sudo` - Ejecuta un comando con permisos de administrador.
- `clear` - Limpia la terminal.

### Windows
- `dir` - Muestra el contenido del directorio actual.
- `cd` - Cambia de directorio.
- `mkdir nombre` - Crea una carpeta nueva.
- `rmdir nombre` - Elimina una carpeta vacía.
- `copy origen destino` - Copia archivos.
- `move origen destino` - Mueve archivos.
- `del archivo` - Elimina un archivo.
- `type archivo` - Muestra el contenido de un archivo.
- `cls` - Limpia la consola.
- `ipconfig` - Muestra la configuración de red del sistema.
- `shutdown /s /t 0` - Apaga el equipo de inmediato.

### Observación
Los comandos básicos varían según el sistema operativo, pero su propósito principal es administrar archivos, carpetas, permisos y servicios del equipo.
